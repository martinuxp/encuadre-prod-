# Encuadre Production API

Skill para operar de forma segura el Portal de Producción de Encuadre mediante la API REST desplegada.

Invocación: `$encuadre-production-api`.

La skill cubre proyectos, contexto de producción, contactos, elenco, crew, fotos de contactos, soft delete y auditoría. No permite acceso directo a Firestore, Storage ni Firebase Admin SDK.
